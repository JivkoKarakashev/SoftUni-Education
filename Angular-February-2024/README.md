## Course Introduction

The "Angular" course provides students with knowledge and practical skills for building client applications (Single Page Applications) with Angular technology, a framework created by Google and one of the most popular at the moment.

Students are introduced to the basic syntax and concepts of TypeScript, as well as its advantages and conveniences over JavaScript when using it to develop applications for browsers and mobile platforms.

They study what Single Page Applications (SPA) is, as well as architectural patterns for SPA applications, components, directives and their implementation in Angular. 

Students also gain knowledge about working with views and templates for data visualization (templates), models, components, data binding, working with multiple views, observables, routing, retrieving data from a REST service and dependency injection (DI).

## Acquired Skills

1. Introduction to Angular and TypeScript
2. Components
3. Dependency injection(DI), Intro to RxJS, Services
4. Modules and Routing
5. Forms
6. Pipes, Interceptors and Subjects
7. State Management
