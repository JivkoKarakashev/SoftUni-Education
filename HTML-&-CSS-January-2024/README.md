## Course Introduction

The aim of the "HTML & CSS" course is to provide basic knowledge of web technologies and more specifically an introduction to HTML5 and CSS3. Students will acquire basic knowledge in web development, web browsers, HTML/CSS/DOM development tools and develop practical skills in using the HyperText Markup Language (HTML) and Cascading Style Sheets Language (CSS). The basic HTML tags, paragraphs, lists, tables, forms, controls and semantic HTML tags will be studied. The emphasis is on basic CSS selectors and styles, working with classes, presentation rules, positioning and layout rules in CSS. The latest innovations in the HTML5 and CSS3 standards are covered. The course will emphasize practical exercises with HTML and CSS, through which students will be involved in real projects for developing web pages, implementing site fragments and creating complete modern websites with a good vision, modern structure and mobile support.
