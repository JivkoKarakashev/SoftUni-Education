## Course Introduction

The course provides knowledge and practical skills for building client applications (Single Page Applications), using one of the most popular frameworks. Architectural patterns for SPA applications, components, and more are studied. Views and templates for data visualization (templates), models, data binding, working with multiple views, routing, and retrieving data from REST services are studied.

The training provides knowledge and practical skills for developing Single Page Applications (SPA) using ReactJS technology - one of the most popular and fast libraries for rendering a client interface, developed and supported by Facebook and Instagram. Special attention will be paid to the JSX syntax, working with requests and Promises, dividing an application into components, routing and form validation, and various ways to style components using techniques such as CSS Modules and Styled Components. New concepts in the library, such as React Hooks and Context API, will also be examined.

## Acquired Skills

2. Components: Basic Idea
3. Components: Deep Dive
