## Course Introduction

The course is intensive and aims to introduce learners to the development of server-side JavaScript applications on the Node.js platform, using Express.js as a framework. During the training, students will understand how to create a server with Node.js, learn server-client architecture and how to make easy and fast data-driven web applications with Node.js, Express.js and MongoDB using modern techniques and tools. One of the most popular non-relational databases - MongoDB - will be considered, along with the Mongoose library for taking data from it. By the end of the course, a complete REST API will be built from scratch, using Express.js and MongoDB. A lot of emphasis is placed on practical exercises that will involve students in real projects for web page development, implementation of site fragments and creation of complete modern websites with a good vision, modern structure and mobile support.

## Acquired Skills

1. NodeJS Streams and Utilities
2. ExpressJS and Templating
3. NoSQL and MongoDB
4. Sessions and Authentication
5. Validation and Error Handling
